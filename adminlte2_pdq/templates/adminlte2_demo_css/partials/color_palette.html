Some colors have other names, which use the color's values unless they are given their own:

    • light-blue for primary
    • aqua for info
    • green for success
    • yellow for warning
    • red and error for danger

Bootstrap's bg-primary, bg-info, bg-success, bg-warning, and bg-danger are pale tints, unless ADMINLTE2_CONSISTENT_COLORS is set, so the background examples on these pages use the other names for those colors. The swatches below show each color's own values.
