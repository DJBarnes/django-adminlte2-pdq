{# Labels #}

On hover, label elements can have a "tooltip" message that shows up.


To implement tooltips, add data-toggle="tooltip", and then title="<message>", where <message> is the text to display in the tooltip.

Optionally, a tooltip can have a color applied in one of two ways:

  1. Add a data-tooltip-color=<color>, where <color> is the desired color to use from existing package color themes.

  2. Add a CSS class of tooltip-<color>, where <color> is the desired color to use from existing package color themes.
