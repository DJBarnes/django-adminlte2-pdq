{# Labels #}

Hover over an element with a tooltip to show its message. Tooltip colors work on any element, not only labels.


To implement tooltips, add data-toggle="tooltip", and then title="<message>", where <message> is the text to display in the tooltip.

Optionally, a tooltip can have a color applied in one of two ways:

  1. Add a data-tooltip-color=<color>, where <color> is a package color.

  2. Add a CSS class of tooltip-<color>, where <color> is a package color.
